# cortexkit-bus-inmemory

> [!WARNING]
> **Alpha.** cortexkit-bus-inmemory is in early development and is not yet released for general use.
> Breaking changes will happen between versions, including changes to its settings,
> stored data and interfaces. Pin an exact version if you depend on it.

Deterministic, process-local implementation of the [bus traits](../cortexkit-bus-trait/README.md).

Add to `Cargo.toml`:

```toml
[dependencies]
cortexkit-bus-inmemory = "0.3.0"
```

See the [crate source](src/lib.rs) for `InMemoryBus`.
