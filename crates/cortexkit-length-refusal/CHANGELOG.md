# Changelog

## 0.1.0

- `classify(family, http_status, body)`: whether a provider's refusal says the request is too
  long for the model's context window, and the request and limit token counts it states, for
  the routing contract's seven wire families.
- `classify_text(text)`: the same from only the words a host kept: a body, a body or inner
  error object behind its status, a bare message, or Claude Code's `Prompt is too long`.
