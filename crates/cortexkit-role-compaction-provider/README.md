# cortexkit-role-compaction-provider

Wire types and vectors for `compaction-provider/v1`: setup, per-step status, compaction replies, request fencing, and readiness notifications.

Add to `Cargo.toml`:

```toml
[dependencies]
cortexkit-role-compaction-provider = "0.3.0"
```

The [contract](CONTRACT.md) is normative. See the [role/conformance guide](../../docs/role-contracts.md) for the available suites and vector locations.
