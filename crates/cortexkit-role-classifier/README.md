# cortexkit-role-classifier

Wire types, validation, and vectors for `classifier/v1` requests and replies.

This crate is not published on crates.io. With a checkout at `../commons`, add:

```toml
[dependencies]
cortexkit-role-classifier = { path = "../commons/crates/cortexkit-role-classifier" }
```

The [contract](CONTRACT.md) is normative. See the [conformance runner](../cortexkit-role-classifier-conformance/README.md) and [role/conformance guide](../../docs/role-contracts.md) for implementation testing.
