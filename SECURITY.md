# Security

## Report a vulnerability

Please report security vulnerabilities privately through [GitHub's private vulnerability reporting form](https://github.com/cortexkit/commons/security/advisories/new). Private vulnerability reporting is enabled for this repository.

Do not disclose an unpatched vulnerability in a public issue, pull request, or discussion.

Include the affected crate and version, the impact, reproduction steps or a minimal proof of concept, and any relevant logs with credentials and personal data removed. Keep exploit details private while a fix and disclosure are coordinated.
